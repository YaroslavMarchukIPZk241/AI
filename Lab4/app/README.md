# QuizLab — локальний генератор навчальних тестів

Застосунок створює тест із чотирма варіантами відповідей на кожне питання за заданою темою, мовою та складністю. Користувач проходить тест і отримує результат. Використовується HTML, CSS, JavaScript та локальна модель Qwen3 через OpenAI-сумісний API Ollama.

## Запуск (Windows)

1. Встановити [Ollama](https://ollama.com/download), Python 3 або VS Code з Live Server.
2. Запустити Ollama та виконати в PowerShell (якщо модель ще не завантажена):

   ```powershell
   ollama pull qwen3:4b-instruct-2507-q4_K_M
   ```

3. Перевірити `ollama list`. Якщо Ollama не працює, запустити її через меню Пуск або `ollama serve`.
4. Відкрити термінал у папці `app` і запустити:

   ```powershell
   py -m http.server 5500 --bind localhost
   ```

5. Відкрити http://localhost:5500/ у браузері. Або запустити `index.html` через Live Server. Не відкривати через `file://`.

Після завантаження моделі інтернет не потрібен. Якщо браузер блокує запит через CORS, повністю закрийте Ollama через системний трей та запустіть у новому PowerShell:

```powershell
$env:OLLAMA_ORIGINS='http://localhost:5500,http://127.0.0.1:5500'
$env:OLLAMA_CONTEXT_LENGTH='4096'
ollama serve
```

Не закривайте термінал, поки користуєтеся застосунком. Якщо Live Server використовує інший порт, вкажіть його точну адресу в OLLAMA_ORIGINS або використайте порт 5500.

## Параметри

- `temperature = 0.2`: невелика випадковість, щоб отримувати різні питання та зменшити ризик помилок.
- `max_tokens = 2048`: обмежує відповідь і дозволяє створити до 8 коротких питань; при перевищенні ліміту застосунок повідомляє про це.
- Контекст 4096 токенів: достатній для короткого промпту та JSON-відповіді, не вимагає великого KV-кешу. Перевірити через `ollama ps` під час або після генерації; якщо контекст відрізняється, перезапустити сервер з `OLLAMA_CONTEXT_LENGTH=4096`, як вище.
- Таймаут 120 секунд: захист від зависання запиту, враховуючи можливе холодне завантаження моделі.
- `response_format: json_object`: модель повинна повернути структурований JSON. Код перевіряє кількість питань, структуру, повтори та коректність індексів. Фактична правильність згенерованих відповідей потребує перевірки людиною.

Вибрано Q4_K_M за результатами локального бенчмарку: швидша генерація та менше помилок, ніж у Q6_K. Модель Instruct без окремого режиму міркування.

## Файли

- `index.html` — інтерфейс.
- `style.css` — стилі, адаптивність.
- `script.js` — запит до `http://localhost:11434/v1/chat/completions`, перевірка JSON, перемішування варіантів, оцінювання.
